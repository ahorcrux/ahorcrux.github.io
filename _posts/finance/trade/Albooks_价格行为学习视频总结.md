+ 如何保持客观，避免情绪干扰？

进行小额交易。这样即使亏损或者盈利也不会有太大的情绪波动。

大部分机构是通过机器进行交易的，而机器是没有感情完全客观的，所以你个人在交易时也需要保持冷静、客观，严格自律的执行自己的交易计划，如果不能保持冷静、客观，情绪波动较大时就不要暂停交易。

## 《08 始终持仓：谁掌握着市场》

价格行为最重要的因素：即市场趋势

在所有级别时间框架下，市场总是处于以下两种状态之一中：

+ 趋势

+ 交易区间

如果你不确定市场处于哪种状态，那它就处于交易区间中

市场一直处于循环中,

+ 趋势突破

+ 趋势通道

+ 交易区间

+ 趋势突破


如果市场处于趋势中，80%的反转都会失败。

例如，如果市场处于熊市中，价格开始出现反转，那么很有可能会演变为熊市旗形

如果市场处于交易区间中，那么80%的突破形成趋势都会失败


始终持仓方向，根据市场前面的上下文来确定趋势，然后选择自己的持仓方向


如果确认了趋势方向，那么就立即入场，如果止损位较远那就轻仓入场

+ 在趋势中： 

1. 价格会朝一个方向移动

2. 在某个时刻，突破阶段会过度到通道阶段

3. 通道对于初学者可能不太容易识别

4. 

+ 交易术语

1. 趋势

2. 摆动

3. 波段

4. 回调

波段比摆动更小，回调是波段的一种

5. 交易区间

交易区间就是没有趋势的状态，即不知道价格会从哪个方向突破

交易区间的策略是低买高卖的超短线交易

每个交易区间都有小的趋势，每个趋势都有小的交易区间

+ 新手总是在等待回调

在趋势突破的强势期间，市场在回调前会走出很长一段行情，新手就会错过大幅行情。

+ 所有交易都要设置保护性止损

+ 市场要么处于交易区间（盘整行情），要去处于趋势行情

如果不确定市场是否处于趋势行情，就按交易区间进行交易

+ 每根K线要么是趋势K线，要么是交易区间K线

趋势K线：实体部分大，影线部分小

交易区间K线：实体部分小，影线部分大

+ K线要结合行情上下文看

如果K线实体部分小，但是市场处于强劲趋势中，那么大概率是趋势K线

如果K线实体部分大，但是市场处于横盘状态（有许多重叠的K线、长影线和频繁的反转），那它就是震荡区间K线

+ K线的影线都是一次失败的突破尝试

例如，某根阳K线的上影线就是价格尝试突破阳K线顶部失败，在收盘时下跌造成的

+ 每一根趋势K线或一系列的趋势K线

都是一次突破

都是一次缺口

都是一个尖峰

都是一个衰竭

都是一次高潮

+ 每一个缺口都是一个趋势K线

当缺口出现在行情启动前，它就是突破缺口

当缺口出现在一个较低交易区间的突破处，它就是测量缺口

当缺口出现在行情后期出现时，它可能就是衰竭缺口，市场可能正式回调或反转


## 《09 交易设置和信号K线》

+ 设置分为2部分

1. 市场上下文

机构更关注市场背景，即 当前处于市场周期哪个阶段 和 解读趋势的强度 、关注抛售压力和买入压力

单根K线、组合K线或形态可能不太重要，当时可能会有帮助。如果想知道右侧会是怎样，先观察左侧行情，市场往往会延续之前的走势。

*** 如果左侧处于强劲趋势中，那么就应该顺着趋势方向交易。 ***

例如，在强劲的多头趋势中，如果出现强劲的看跌反转K线也无关紧要，你不应该做空，如果要操作，应该只做多。这种情况可以等待几根K线，看看空头会在哪里止损，空头止损的位置就是做多的位置。
因此，在强劲的趋势中，应该把每个反转形态看作是一个顺应趋势的进场信号，而不是做反转。

反转确实会发生，但反转不仅仅是一个K线形态。参考后续《反转》章节

如果左侧处于交易区间中，那么就应该顺着交易区间方向交易。

2. 信号K线

+ 信号K线和进场K线

1. 牛市中反转多头单信号K线要求

最低要求 

收盘价高于K线中间点

收盘价高于开盘价（阳柱实体）

附加要求

开盘价接近或低于前一根的收盘价

收盘价远高于前一根的收盘价

下影线约为整根K线的三分之一到2分之一，K线收盘价位于或接近其最高价

上影线很短或几乎没有

最佳多头信号K线与前一根K线的重叠部分不多

信号K线后的K线不是十字星内含K线

信号K线的收盘价反转前面多根K线的收盘价极值 

2. 熊市中反转空头单信号K线要求与上述相反

3. 双K线反转

+ 反转K线超过2根K线即是双K线反转

+ 双K线反转不一定要是两根连续的K线，例如，先出现一根大的空头趋势K线，然后5、6根K线之后出现同样大的多头趋势K线。

这种不连续的双反转K线在高级别时间周期上就是绝佳的单反转K线

*** 市场背景远比实际信号K线重要的多 ***

一根强劲的信号K线不足以成为进场理由，其市场背景即上下文必须合适。

例如：

1. 交易区间

在一个交易区间中，交易应该低买高卖，如果你在区间顶部发现一个比较好的买入信号K线，那么这个交易机会就不佳，因为大多数交易区间的突破都会失败

2. 强劲趋势

小幅强劲趋势、急涨或突破行情

大多数反转信号都会失败，这种市场背景只需顺势交易

3. 弱势趋势（波动幅度较大的通道）

可以双向交易。

如果要做逆势交易，需要看到强烈的和趋势相反的卖出信号柱

例如，在弱势的多头趋势中，你需要确认：

+ 卖出的压力的证据

+ 非常好的卖出信号K线

4. 绝佳的交易机会不一定需要强劲的信号K线

例如，在强劲的多头趋势中，信号K线通常比较弱，但还是可以顺着趋势做多

5. 弱势市场背景中，出现了信号可以选择等待（趋势突破）或第二次信号进场

6. 在第二个信号出现时买入更多仓位

## 《11 通道》


通道是弱趋势的表现，通道可以很陡峭和强劲，但是它不如突破强劲

牛市趋势中，趋势线在下方，通道线在上方；
熊市趋势中，趋势线在上方，通道线在下方；


每次市场在通道线突破失败后，你需要用突破失败的K线极值点（即上/下影线）重新绘制一条通道线。

通道往往会变得更平缓、更水平，范围也会更宽广，最终变成交易区间。

当市场到达通道顶部或底部测试时，它有两种可能：

1. 突破

2. 反转

这提供了比较好的交易机会。最好的办法是寻找反转信号，并在反转时入场，然后预期市场会测试通道另一侧。

市场处于永无止境的循环中：

+ 趋势突破阶段

+ 通道阶段

+ 交易区间阶段

+ 趋势突破阶段

通道是趋势强劲阶段、急涨阶段、突破阶段和交易区间阶段之间的过渡形态。

大多数上升通道应该被看作是看跌旗形。
例如牛市通道应被看作是熊市旗形，应为大多数上升通道会向下突破，起作用与看跌旗形完全相同。

每当看见上升通道时，应始终将其视为看跌旗形，预期它最终会向下突破


在趋势中，市场一开始会以尖峰或突破的形式发展，然后回调，会有一些双向交易发生，接着进入通道阶段。

+ 多头通道向交易区间的转变


很少有趋势突破通道继续延续之前的方向的情况，这种情况下，通常：

+ 趋势会在5根K线内失败

牛市通道顺势突破成功后会转而向下，熊市通道顺势突破成功后会转而向上

+ 市场会反转重新回到通道内

+ 市场会测试通道另外一端

+ 通道的起始阶段通常会进入一个交易区间

牛市通道顺势突破成功后会转而向下，熊市通道顺势突破成功后会转而向上，最后横向波动进入交易区间的一部分。两者都是加速趋势的尝试

通道的特征：

1. 通道内的K线可多可少

+ 通道可以是非常多根K线组成，包含图表的所有部分。

+ 通道也可以是非常少的K线组成，例如仅有2根K线组成。

2. 通道间距可以非常宽也可以非常窄

+ 通道可以非常宽，波动幅度大，很多K线上下波动，类似交易区间

+ 通道可以非常窄，非常陡峭和垂直，类似突破形态

3. 通道的两条线不一定是平行的

图表中任意被两条线包含的部分，不管这两条线是否平行，都处于通道中。

+ 通道可以是水平的，例如交易区间也是一种通道

+ 通道可以是倾斜的，例如楔形形态

+ 通道可以是扩散的，例如扩散三角形

+ 通道可以是收敛的，例如三角形（楔形也是三角形的一种）

+ 市场总是处于通道中，许多通道需要查看其他时间框架才能发现

+ 一个时间框架内的通道（例如牛市通道）可能只是其他时间框架通道（例如熊市通道）的一部分


趋势行情总是由两部分组成：

+ 急速（突破）阶段

突破阶段、没有回调、单边交易行情

+ 通道阶段

通常有回调、双边交易行情

少数情况下K线有轻微重叠但无实际回调（微通道）


回调的最低要求：

+ 在牛市中，回调的最低要求：当前K线的低点低于前一根K线的低点，那么当前K线就是回调。

+ 在熊市中，回调的最低要求：当前K线的最高点高于前一根K线的最高点，那么当前K线就是回调。
